Mode d'emploi.

👆

Choisis pour qui

Touche une tuile dans « Pour qui ? » (Maman, Papa…) : la page ne montre plus que les idées pour cette personne, dans son budget. « ✎ Mes personnes » permet de changer les prénoms, les budgets et ce qui leur plaît.

🔎

Cherche

Tape un mot dans la barre de recherche (« parfum », « Lego », « pull ») ou choisis une marque dans le menu « Marque ». « Voir le deal » ouvre le site du magasin.

♡

Garde tes idées

« Garder » met un produit de côté dans « Ma sélection », avec le total par personne. Tout reste sur ce téléphone ou cet ordinateur, sans compte.

⏱

Suis un prix

« Suivre le prix » sur une fiche, ou « Suivre un produit » avec n'importe quel lien. Un formulaire GitHub s'ouvre déjà rempli : indique ton prix cible et valide. Pour arrêter, ferme la demande.

🔗

Partage

« Partager » crée un lien avec tes personnes et ta sélection. La personne qui l'ouvre peut les ajouter à sa page. Attention aux surprises : n'envoie pas tes idées à celui qui va les recevoir.

Page mise à jour automatiquement à chaque passage du bot. Les deals restent affichés 7 jours après leur dernière apparition. Vérifie toujours le prix sur le site avant d'acheter.
